# Meu Controlo Android

Aplicação Android instalável que abre o Meu Controlo em janela própria e aparece na gaveta de aplicações.

## Gerar o APK no GitHub
1. Crie um repositório separado, por exemplo `meu-controlo-android`.
2. Envie todo o conteúdo desta pasta.
3. Abra **Actions > Criar APK Android > Run workflow**.
4. Depois do visto verde, abra a execução e descarregue o artefacto **Meu-Controlo-APK**.
5. Extraia o ZIP do artefacto e instale `app-debug.apk` no Android.

O endereço publicado já está configurado em `app/build.gradle`.
